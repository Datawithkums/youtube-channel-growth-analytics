# YouTube Channel Growth & Monetization Analytics

## Project Overview
An end-to-end Data Analytics project focused on analysing my own YouTube channel, **Data with Kums**.

## Business Objective
To identify opportunities to:
- Increase video views.
- Improve audience retention.
- Grow subscribers.
- Increase watch time.
- Understand monetization opportunities.

## Tools & Technologies
- Microsoft Excel
- MySQL
- Python (Pandas, Matplotlib)
- Power BI

## Key Business Questions
1. Which videos generate the highest views?
2. Which topics attract more subscribers?
3. What is the audience retention trend?
4. How do Shorts compare with long-form videos?
5. How close is the channel to YouTube monetization eligibility?

## Data Source
YouTube Studio Analytics exports.
